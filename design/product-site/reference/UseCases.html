runemark/Use cases

Use cases

Four jobs runemark gets hired for. Each one names what you need and where to start.

01CI · GitHub Actions

Publish a CI log as a readable page

The coloured log of a job is gone once the run page is closed. Rendered, it is a static page anyone can open, search and link to.

  1. 1Write the job's output to a file, colours included.
  2. 2Render it; a colour pair below 4.5:1 fails the step.
  3. 3Upload the page with the rest of your site.
Quickstart Example: test report

02Docs · Build time

Show real command output in your docs

Capture the command once, commit the file, render it in the build. The page shows what the tool printed, not a screenshot of it.

03Testing · CI

Catch rendering regressions

04Accessibility

Reports a screen reader can read

Terminal output is read as plain text. A report with columns is a table, not aligned spaces.

Contrast rules
Markup
<pre>, <table>
Contrast
Every colour pair checked against 4.5:1
Flag
--strict-contrast

The price

What it is not for

This design has a price, and it is better read here than found later.

  • It is not a terminal: no alternate screen, no mouse reporting.
  • The page shows a frame, not a live session.
  • Wide glyphs are measured by a table that is updated with Unicode.
